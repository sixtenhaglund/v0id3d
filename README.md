# V0ID3D

**Play it here: https://sixtenhaglund.github.io/v0id3d/**

Reality is breaking. Find the glowing shards (the broken pieces of a seal) and bring
them to The Anchor before the timer runs out. From one minute left the world starts to
fall apart, and something in the lightning comes for you.

## Controls

| Key | What it does |
| --- | --- |
| WASD / arrow keys | move |
| Space | dash forward (recharges in 2.5 seconds) |
| E | deliver your shards at The Anchor (+10 seconds each) — or use a Locator to find the nearest shard |
| F | fullscreen |
| M | mute |
| Esc | pause |

Click the screen first — browsers only allow sound after you click.
